## The shared system (already built — use it, don't reinvent)
- `tpl/cinema.css` — the skin. Loaded via the marker `<!--@cinema-css-->` placed **right after the page's own `<style>…</style>` block in `<head>`** (build.js replaces it with the inlined web fonts + skin). It re-tokens the palette (dark-first; `[data-theme="light"]` = paper), sets fonts (`--display` Fraunces for h1/h2, `--body` Newsreader, `--ui` Inter), and restyles `.widget` (now a "stage": gradient surface, hairline top highlight, deep shadow), `.callout`, `.derive`, `.check`, `.next-card`, range inputs (glowing thumb), tab/preset buttons (`.on`/`aria-pressed` glow), `.play` gradient button, `.reveal`/`.reveal-stagger` scroll choreography, `.glow-1..7` SVG drop-shadow utilities, `.stage-canvas` (+`.hud`, `.hint`) for 3D containers. Read the file once — every class is documented by its rule.
- `tpl/cinema.js` — the runtime. Loaded via the marker `<!--@cinema-js-->` placed **immediately before the page's first `<script>`** (build.js replaces it with `<script src="vendor/three.min.js">` + the runtime). API on `window.Cinema`:
  - `reveal()` runs on DOMContentLoaded for `.reveal` / `.reveal-stagger` elements (reduced-motion safe). Add `reveal` to every section's first prose block, every `.widget`, every `.derive`, every `.fig`; `reveal-stagger` on grids of cards/chips.
  - `stage3d(container, {camera:{pos,look,fov}, orbit:true, zoom:false, autoRotate:0.15, autoRotateStopsOnUser:true, aspect:.62, build(ctx), update(ctx,t,dt)})` → `{ctx, render, requestRender, setAutoRotate, dispose}`. `ctx = {THREE, scene, camera, renderer, root, colors, isLight, hex, lerpColor, ramp, look, orbit}`. Pauses off-screen; respects reduced motion; drag-to-orbit built in. Give the container an explicit height (`style="height:420px"`; ≤ 320px under 640px via CSS).
  - `Cinema.prim.*(ctx, …)`: `arrow(a,b,colorHex,{radius,head})` (glowing arrow, `.userData.set(a,b)` to move it), `grid(size,div,colorHex,{opacity,vertical})`, `axes(L)`, `surface(f,{x,y,res,ramp:[c1,c2,c3],zscale,wire,opacity})` (lit, colour-ramped height field; `userData.geo/mesh` for live updates: rewrite `position` attr + `computeVertexNormals()` + `needsUpdate`), `dot(pos,colorHex,r)`, `path(points,colorHex,{opacity})`, `glass(w,h,colorHex,opacity)` (translucent plane), `label(text,pos,{size,color,bg,scale})` (sprite text).
  - `Cinema.glowFilter(svg)` returns `url(#glow)` for SVG glow; `Cinema.colors()` reads the live palette; `Cinema.hex(cssColor)` → int; `Cinema.ramp(t,a,b,c)`; `Cinema.ease.out/inOut`; `Cinema.reduced`.
  - Colours for three.js: always `Cinema.hex(Cinema.colors().s1)` etc. — never hardcode hex so the light theme stays right. Re-read colours if the theme toggles (listen for `data-theme` attribute changes with a MutationObserver and rebuild materials, or simply rebuild the stage).

## What "cinema" means in practice (the bar)
1. **Every widget is a stage, and the picture is the hero.** Bigger canvases (the plot fills the stage; controls sit in a slim rail below or beside), no cramped ±4 planes with a tiny drawing in the middle. Dark glass HUD chips for live readouts. Cursor/touch hints in the corner.
2. **Glow and depth.** Vectors, curves, and highlighted entries glow (`.glow-N` or `glowFilter`); grids fade toward the edges (radial mask); surfaces are lit. Light theme drops the glow automatically.
3. **Real 3D where the idea is 3D** — via `stage3d`, orbitable, with a slow auto-rotate that stops when the user grabs it. Unit 1 minimum: the determinant cube (`w-det3`) as a lit parallelepiped with a ghost unit cube and a volume HUD; the three planes (`w-pl3`) as translucent glass planes with the intersection point/line glowing; the column picture of `Ax=b` (`w-windows` "columns" tab, or `w-machine`) as 3D arrows with the reachable plane/line drawn as glass. Add more where it earns its place (e.g. the null-space beam as a 3D shadow projector for `w-null`).
4. **Choreography, not jump cuts.** Every stage change tweens (`tween()` from the house runtime or your own rAF with `Cinema.ease`); "▶ play" runs a 2–4 s story (elimination sweeping the matrix into a staircase row by row with the pivot flashing; the machine morphing the grid from identity; the three fates cycling). Reduced motion → instant states.
5. **Opening shot.** The unit hero gets a full-width cinematic opener: a `stage3d` (or canvas) backdrop behind the title — for Unit 1 a grid being sculpted by a slowly-changing matrix with glowing basis vectors — with the title, kicker, lede and chips over it (readable: add a gradient scrim). Auto-rotates/animates gently; stops under reduced motion.
6. **Static figures upgrade too.** The SVG figures added in round 7 get the skin: glow on the key stroke, `.fig` frame, motion on reveal where cheap (draw-on via `stroke-dasharray` animation).
7. **Typography and rhythm.** `h1` Fraunces, section numbers as big soft numerals (`.sec-num` restyled), generous spacing, `.kicker` uppercase tracking. Nothing else about the prose changes — the words are already approved.
