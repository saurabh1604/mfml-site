Bars: slots n=0..14 (`exp`), m=0..14 (`cos`), n=1..14 (`ln`), height = log10 of |term| mapped from [−12, +4] to the plot (bars below 1e−12 clipped to the floor); bars up to `fc-n` (terms kept) in s1, the rest dimmed; a glowing s2 line with dots plotting `|series − partial sum after n terms|` for each n (the actual truncation error) — for `exp` this hugs the next term's bar (the remainder ≈ next term), which is the point. A dashed level line at 10⁰ = 1 labelled `1`. Y ticks at 10⁴, 10⁰, 10⁻⁴, 10⁻⁸, 10⁻¹². Readout: `largest term: n = … (size …)` (the hump), `terms kept: n = …`, `partial sum = …`, `true value = …`, `error = …` (toExponential(2)). Verdict: exp/cos good `✓ n! beats |x|ⁿ — the error after the hump falls factorially`; ln with |x|≤1 info `radius of trust: |x| ≤ 1 — terms shrink like xⁿ/n, slowly`; ln with x>1 bad as above.
