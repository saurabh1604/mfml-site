### Act II — A cell that talks
**s4 · Many jobs, one cell.** Keep the four shapes (many→one, one→many, many→many aligned, many→many different lengths) and **w-shapes**; keep the read-out example after "the train to": scores Delhi 2, Mumbai 1, late 0.5, the −1 → **0.609, 0.224, 0.136, 0.030**, step loss −ln 0.609 ≈ **0.495**.

**s5 · An RNN language model: learning to talk, then talking.** New. Training: at every word the read-out guesses the next word; the total loss is the sum of the surprises; the true previous word is fed in at every step — **teacher forcing** ("training wheels"). Generating: pick a word from the read-out, then **feed it back in** as the next input — "a machine that talks by listening to itself". Choosing the word: greedy (always the top) is dull and loops; **sampling with temperature** (Unit 14): same scores (2, 1, 0.5, −1): T = 1 → (0.609, 0.224, 0.136, 0.030); T = 0.5 → **(0.842, 0.114, 0.042, 0.002)** (bold, repetitive); T = 2 → **(0.434, 0.264, 0.205, 0.097)** (adventurous, error-prone). **Exposure bias** trap: during training the cell always saw the true previous word; while talking it sees its own guesses, so one early mistake can snowball. Widget (new): **w-talk** — a tiny RNN language model **trained by you offline** (e.g. character-level on ~300 railway-announcement / everyday sentences you write, hidden size 24–48; train with numpy in `dev/train-u17-talk.py`, embed the weights; say plainly on the page it is a tiny model trained for this page). Buttons: generate (greedy / sample), temperature slider (0.2–2), seed text box; show the probability bars for the next character at each step and the hidden state as a heat strip; a "teacher forcing vs free running" toggle that shows the difference in what is fed back.

### Act III — Blame through time
**s6 · Backprop through time.** Keep the step machine (**w-bptt**) and the worked chain ∂h₃/∂h₂ = w(1 − h₃²) ≈ **0.4838**, ∂h₂/∂h₁ ≈ **0.4340**, product ≈ **0.2100**. Deepen: (1) the gradient for W is a **sum over time steps** — every word casts a vote on how the shared W should change; (2) in matrix form each backward step multiplies by the Jacobian diag(1 − hₜ²)·W — the same W again and again (that is the seed of s7). New: **truncated BPTT** — cut the backward walk every k steps to save memory and time: a 1 000-word text with k = 20 becomes **50** chunks; the price is that no gradient links words more than k apart, so dependencies longer than k are hard to learn.

**s7 · Why memory fades or explodes.** Anchor: **a whisper passed down a line of people** (the Telephone game) — each person repeats it at a fixed fraction of the loudness they heard; below 1 it fades to nothing, above 1 it becomes a shout. Keep: w^T with 0.5¹⁰ ≈ **0.000977**, 1.5¹⁰ ≈ **57.67** (and 0.9²⁰ ≈ 0.1216, 1.1²⁰ ≈ 6.7275 if useful); the matrix case with W = [[0.9, 0.4], [0.1, 0.6]], eigenvalues **1** and **0.5**, eigenvectors (4, 1) and (1, −1), v = (1, 0) = 0.2·(4, 1) + 0.2·(1, −1) → Wᵗv → (0.8, 0.2): "the part along the λ = 1 direction survives, the rest halves each step" (Unit 4). Say it plainly: the largest |λ| (the spectral radius) decides; tanh′ ≤ 1 only makes fading worse. Why it matters: a long-range dependency (subject–verb agreement: "The **keys** to the old wooden cabinet in the hall **are** …") cannot be learned if the blame from "are" never reaches "keys". Widgets **w-power** (keep; fix the overlapping "one thousandth" label and tick labels) and **w-eigen-memory** (rebuild for clarity: the 2-D plane with the two eigen-directions drawn, the vector's path Wᵗv as dots, and beside it a plain 2-D chart of ‖Wᵗv‖ (log scale) **with the bars it promises**, plus the two components along each eigen-direction as lines; presets fade / keep / explode / rotate; the 3-D "time as height" view may stay as an optional tab only if it is clearer — otherwise drop it).

**s8 · First aid for explosions: clip the gradient; start at the right volume.** Keep clipping (g = (30, 40), ‖g‖ = 50, c = 5 → **(3, 4)**; "rescale the step, keep the direction") and **w-clip** (check). Add one paragraph: good starting weights — an orthogonal (or identity-like) W has all |λ| = 1, so the whisper starts at normal volume.

### Act IV — Gates, and reading both ways
**s9 · The LSTM: a memory with an express lane.** Keep the current section's content (bahi-khata ledger, three valves, the express lane, ∂c_T/∂c_k = Πf, 0.9¹⁰ ≈ **0.349** vs 0.5¹⁰, the honest 0.9⁵⁰ ≈ **0.00515**, 0.99⁵⁰ ≈ **0.605**). Add the **full worked step** with every gate computed from weights (scalar LSTM, x = 1, h_prev = 0, c_prev = 1; pre-activations z_f = 2x, z_i = 0, z_o = x, z_g = x): f = σ(2) = **0.8808**, i = σ(0) = **0.5**, o = σ(1) = **0.7311**, g = tanh(1) = **0.7616** → c = 0.8808·1 + 0.5·0.7616 = **1.2616**, h = 0.7311·tanh(1.2616) = 0.7311·0.8515 = **0.6225**. Add the practical nugget: the forget-gate bias is usually started at 1–2 so the lane begins open (σ(1) ≈ 0.73, σ(2) ≈ 0.88). Foreshadow: the express lane is the same trick as the transformer's residual path (Unit 18). Widgets **w-notebook** (tank; keep, check), **w-lstm** memory lab (keep; fix the overlapping axis labels "20 sentence length / 30 sentence length"; check every number).

**s10 · The GRU: one blend dial.** Keep (blend h = (1 − z)·h_prev + z·h̃; parameter counts for h = 128, d = 64: plain **24 704**, GRU **74 112**, LSTM **98 816**). Add the full worked step: h_prev = 0.5, x = 1, z = σ(0) = **0.5**, r = σ(2) = **0.8808**, candidate h̃ = tanh(1·x + 1·(r·h_prev)) = tanh(1.4404) = **0.8938**, h = 0.5·0.5 + 0.5·0.8938 = **0.6969**; explain the reset gate as "how much of the old note to consult while drafting the new one". Comparison table plain / GRU / LSTM (gates, memories, parameters, when to choose). Widgets **w-gru** (fix the "1 × new note" label overlap), **w-gates-compare** (keep).

**s11 · Reading both ways, and stacking.** New. **Bidirectional RNN**: one cell reads left→right, another right→left; each word's final note is the two notes side by side. Anchor example: "He said **Teddy** bears are on sale" vs "He said **Teddy** Roosevelt was a president" — whether Teddy is a name depends on the *next* word. Worked (scalar, w = 0.5, u = 1, tanh, x = (0, 0, 1)): forward notes **(0, 0, 0.7616)**, backward notes **(0.1797, 0.3634, 0.7616)** — word 1 learns about word 3 only through the backward reader; concatenated notes e.g. word 1 = (0, 0.1797). Trap: a two-way reader cannot be used to *generate* text — the future is not written yet. **Stacked (deep) RNNs**: layer 2 reads layer 1's notes, like floors of a building (time × depth grid); lower floors catch local patterns, higher floors longer-range ones. Parameters (h = 128, d = 64): one-way one layer 24 704; two-way **49 408**; two stacked layers **57 600** (24 704 + 128·(128+128) + 128). Widget (new): **w-bidir** — a sentence with tags; toggle one-way / two-way; the forward and backward chains drawn above and below the words, each word's concatenated note as two coloured halves; click a word to see which other words can influence its note; a "stack" toggle showing a 2-layer grid.

**s13 · Choosing and grading the words: greedy, beam, BLEU.** Keep greedy vs beam (greedy **0.20** vs beam **0.36**; **w-beam**). New: how to grade a translation without a human — **BLEU**: candidate "the train is late", reference "the train is running late": unigram precision **4/4 = 1**, bigram precision **2/3** (the train ✓, train is ✓, is late ✗), brevity penalty e^(1 − 5/4) = **0.7788**, BLEU-2 = 0.7788·√(1·⅔) ≈ **0.636**. Trap: BLEU only counts overlapping pieces — a correct translation with different words can score low. Widget (new, small): **w-bleu** — type a candidate against a fixed reference; matched n-grams highlighted; precisions, brevity penalty and score update.
