### The worked example (every number pre-verified by the lead with numpy — re-verify in `verify-math15.py`)
Network 2 → 3 → 2 → 1, ReLU after every linear layer (including the output), loss L = ½(ŷ − y)². Predict salary (lakhs) from age = 30, experience = 10; true y = 50.
W(1) = [[0.1, 0.3], [0.2, −0.1], [−0.1, 0.2]], b(1) = (1, −1, −1); W(2) = [[1, −0.5, 1], [1, 0.5, −1]], b(2) = (1, −2); W(3) = [4, 2], b(3) = 2.
Forward: z(1) = (7, 4, −2) → a(1) = (7, 4, 0) (third neuron asleep); z(2) = (6, 7) = a(2); z(3) = 40 = ŷ; L = 50, error ŷ − y = −10.
Backward: ∂L/∂ŷ = −10; ∂L/∂z(3) = −10; ∂L/∂W(3) = [−60, −70], ∂L/∂b(3) = −10, ∂L/∂a(2) = (−40, −20); ∂L/∂z(2) = (−40, −20); ∂L/∂W(2) = [[−280, −160, 0], [−140, −80, 0]], ∂L/∂b(2) = (−40, −20), ∂L/∂a(1) = (−60, 10, −20); ∂L/∂z(1) = (−60, 10, 0) (the −20 is blocked by the sleeping ReLU); ∂L/∂W(1) = [[−1800, −600], [300, 100], [0, 0]], ∂L/∂b(1) = (−60, 10, 0).
Update η = 10⁻⁵: W(1) = [[0.118, 0.306], [0.197, −0.101], [−0.1, 0.2]], b(1) = (1.0006, −1.0001, −1); W(2) = [[1.0028, −0.4984, 1], [1.0014, 0.5008, −1]], b(2) = (1.0004, −1.9998); W(3) = [4.0006, 2.0007], b(3) = 2.0001. Re-run: ŷ = 43.8527, L = 18.89 (loss 50 → 18.89; error −10 → −6.15). With η = 10⁻⁴: ŷ ≈ 79.29, L ≈ 428.8 (overshoot). With η = 10⁻³: ŷ ≈ 508.9. Why: ∂L/∂W(1)₁₁ = −1800 vs ∂L/∂b(3) = −10 — the raw input age = 30 multiplies the first layer's gradients; the real fix is scaling the inputs (Unit 10). The handout says all 17 gradients were checked by finite differences (largest disagreement 5 × 10⁻⁸) — reproduce such a check.

### Other pre-verified numbers for this unit
- Collapse: W₁ = [[1, 2], [0, 1]], b₁ = (1, 0), W₂ = [[1, −1], [2, 1]], b₂ = (0, 1) ⇒ W₂(W₁x + b₁) + b₂ = [[1, 1], [2, 5]] x + (1, 3). Two linear layers = one linear layer; a hundred of them too.
- Fold by fold: the hat (tent) h(x) = ReLU(x) − 2·ReLU(x − 1) + ReLU(x − 2) is 0 at x = 0, 1 at x = 1, 0 at x = 2, 0 for x ≥ 2. Three ReLU neurons make one bump; bumps add up to any curve (piecewise-linear approximation → universal approximation, told as "enough folds can trace any shape").
- Classification head (from Unit 14): scores z = (2, 1, 0), true class 1 ⇒ softmax q = (0.665, 0.245, 0.090), loss = −ln 0.665 ≈ 0.408 nats, ∂L/∂z = q − y = (−0.335, 0.245, 0.090). If the layer below fed a = (1, 2): ∂L/∂W = (q − y) aᵀ = [[−0.335, −0.670], [0.245, 0.489], [0.090, 0.180]]. The same "prediction − truth" as regression's ŷ − y: that is the aha.
- Sigmoid's slope is at most 0.25, so through 5 sigmoid layers the blame shrinks by at least 0.25⁵ ≈ 0.00098, through 10 by 0.25¹⁰ ≈ 9.5 × 10⁻⁷ (vanishing gradient). ReLU's slope is 0 or 1 (no shrinking while awake; dead while asleep).

**Act I — what a network is made of**
- **s1 · A network is a stack of simple steps.** Units 1–14 gave the parts: matrices that move space, the chain rule, gradient descent, softmax. Now we bolt them together. A layer = "multiply by a matrix, add a shift, then bend". Meet the salary network (age, experience → salary) and the shape rule: W(l) is (nodes in layer l) × (nodes in layer l−1). **w-anatomy**: the 2-3-2-1 network drawn three ways, tabs — graph view (nodes/edges), matrix view (the six matrices/vectors with their shapes), chain view (the handout's "eight nodes in one line": a(0) → z(1) → a(1) → z(2) → a(2) → z(3) → ŷ → L); hovering an object highlights its twin in the other views; a shape quiz toggle. End with the roadmap.
- **s2 · One neuron is a line and a bend.** z = w·x + b draws a line across the plane (Unit 13's line, without the street); the activation bends the flat plane along that line. ReLU (a fold/crease — "a hinge"), sigmoid (a smooth step — a probability, Unit 14), tanh, and "none". **w-neuron (3-D)**: the surface a = act(w₁x₁ + w₂x₂ + b) over the plane; sliders w₁, w₂, b; activation picker; the crease line glows on the floor; derivative overlay (slope map: 0/1 for ReLU, ≤ 0.25 for sigmoid). Checks.
- **s3 · Why the bend matters: straight layers collapse.** Two linear layers = one (worked collapse above), so depth without bends buys nothing. **w-collapse (3-D or lavish 2-D "space view")**: a grid of the plane pushed through a 2-2-2 network layer by layer (Unit 1's "a matrix moves space"); toggle activation none/ReLU/tanh: with none, every layer keeps grid lines straight and parallel and the whole stack equals one matrix (shown live: the product W₂W₁); with ReLU the space folds; a two-spirals/two-moons dataset rides along so you see folding untangle it. Checks. Drawer: the collapse algebra; why an affine map of an affine map is affine.
- **s4 · Fold by fold: a network can draw any shape.** One ReLU = one crease; three make a hat (worked); many hats add up to any curve. Universal approximation told honestly: "enough neurons in one hidden layer can get as close as you like — but it does not say how many, or how to find the weights". Width vs depth: each extra layer can fold the already-folded paper again (a strip folded k times has 2ᵏ pieces). **w-folds**: a target curve (preset: sine, a step, |x|, a bump, draw-your-own); a 1-hidden-layer ReLU net with N neurons (1…24) whose output weights are solved by least squares (Unit 3) for fixed evenly-spaced creases — each neuron's hinge drawn faintly, their weighted sum boldly; error readout vs N. A second mode "fold again": the paper-folding depth demo (1–4 layers of |x|-style folds, count the pieces). Checks. Drawer: the hat from three ReLUs.

**Act II — the forward pass**
- **s5 · The forward pass, by hand.** Walk the chain left to right: F1…F7 with every row written out (his "row 1: (0.1)(30) + (0.3)(10) + 1 = 7"); the sleeping third neuron; "keep all of these — the backward pass will ask for them" (the cache). **w-forward**: matrix view — at each step the matrix, the input column and the result light up row by row (row × column as a dot product, Unit 3), with the shape badge ✓; edit the inputs (age, experience) and watch everything recompute; "wake/sleep" indicator on each hidden neuron. Checks.
- **s6 · What comes out, and how we score it.** Two heads. Regression: ŷ and L = ½(ŷ − y)² — Unit 14 showed this is Gaussian likelihood; ∂L/∂ŷ = ŷ − y ("the ½ is there only to cancel the 2"). Classification: scores → softmax → cross-entropy (Unit 14); ∂L/∂z = q − y (worked numbers above). **Same shape of answer: prediction − truth.** **w-heads**: side-by-side — a regression head (drag ŷ, see L and ŷ − y as an arrow) and a 3-class classification head (drag the three scores, see q, the loss, and q − y as three arrows); a toggle "same story" that aligns the two arrows. Checks. Drawer: ∂/∂z of −log softmax = q − y (brief; Unit 14 has the full one — link it).

**Act III — the backward pass**
- **s7 · Two kinds of arrow, two rules.** The whole network alternates linear, ReLU, linear, ReLU… so walking back needs only two rules. Rule A (ReLU arrow): ∂L/∂z = ∂L/∂a ⊙ ReLU′(z) — a switch: pass the blame where the neuron was awake, block it where it slept. Rule B (linear arrow): ∂L/∂W = ∂L/∂z · aᵀ (outer product — "each weight's blame = the blame at its output × what flowed in through it"), ∂L/∂b = ∂L/∂z, ∂L/∂a = Wᵀ ∂L/∂z ("forward you multiply by W, backward by Wᵀ: same wires, opposite direction"). The shape rule that places every transpose. A blame analogy: after a lost match, the review shares the blame by how much each player contributed. **w-rules**: two small interactive panels — Rule A: a vector of incoming blame and a vector of z's; toggle any z's sign and watch its switch open/close; Rule B: a 2×3 W, an a and a ∂L/∂z; the outer-product grid ∂L/∂W builds cell by cell, and Wᵀ∂L/∂z builds column by column with the same wires drawn backwards. Checks. Drawer: Rule B's three results from the scalar chain rule (his (i)/(ii)/(iii)).
- **s8 · The backward pass, by hand.** B1…B7 with every number (as above), the gradients table per layer, the three moments to notice: the neuron with the bigger weight (4 vs 2) gets twice the blame; the third column of ∂L/∂W(2) is all zero ("a weight that carried nothing gets no blame"); the −20 blocked at z(1) ("a neuron that slept on the way forward learns nothing on the way back"). **w-stepper (flagship of A; successor of `backprop-step-machine.html`)**: the handout's "whole thing in one picture": the eight-node chain (and the network graph above it) with a blue value row and a red ∂L/∂node row; ◀ / ▶ / play through the 17 steps (F1–F7, S, B1–B7, update, re-run); each step shows the formula instance with the numbers plugged in, the rule used (A or B), and animates the flow along the wires; click any node for value / local derivative / incoming gradient; a "cache" tray fills during the forward pass and is consumed during the backward pass. Checks. Drawer: the four formulas together with shapes.
- **s9 · Update, check, and why η had to be tiny.** θ ← θ − η ∂L/∂θ (Unit 9). η = 10⁻⁵: loss 50 → 18.89. η = 10⁻⁴: overshoot to ŷ ≈ 79.3, L ≈ 429. The gradients are lopsided (−1800 vs −10) because age = 30 multiplies layer-1 gradients — the real fix is scaling the inputs (Unit 10). Gradient checking: nudge one weight by ±h, compare (L(θ+h) − L(θ−h)) / 2h with backprop's number. **w-train1**: train the salary network on its one example (and optionally a small synthetic salary dataset): η slider (log scale, 10⁻⁶…10⁻³), "scale inputs" toggle (age/100, exp/10 — watch a much larger η become safe), step/run, loss curve on a log axis, ŷ approaching 50; a gradient-check panel listing all 17 parameters' backprop vs finite-difference values and their relative error. Checks.

**Act IV — build your own**
- **s10 · When the blame fades, explodes, or dies.** Vanishing: every sigmoid layer multiplies the blame by at most 0.25 (0.25⁵ ≈ 0.001, 0.25¹⁰ ≈ 10⁻⁶); tanh ≤ 1; ReLU exactly 1 while awake. Exploding: big weights multiply up (a preview of Unit 17's eigenvalue story). Dead ReLU: a neuron whose z is negative for every input never learns again (his "too many sleeping at once"). Fixes named, not proved: ReLU-family activations, careful initial weights (scale ≈ 1/√fan-in), scaled inputs, Adam (Unit 11). **w-depth (3-D)**: a deep narrow network (depth 2…20) drawn as a tower of layers; a red blame pulse travels back down; each layer's bar height = the size of its gradient (log scale); pickers for activation (sigmoid/tanh/ReLU) and weight scale (0.5/1/2 × 1/√n); a "kill" slider for the bias that pushes ReLUs asleep.
