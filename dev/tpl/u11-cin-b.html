Standard form is one shape: minimise \(f\) subject to \(g_i(\mathbf x)\le 0\) and \(h_j(\mathbf x)=0\). Every rule is pushed into it — a \(\ge\) is multiplied by \(-1\), an \(=\) is kept as it is (or split into two \(\le\)), and a strict \(<\) is simply not allowed, because a set with no smallest allowed value has no answer to find.
