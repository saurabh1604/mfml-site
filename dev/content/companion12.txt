1     The Intuition: Why Do We Need PCA?
Imagine you have a dataset with many features—say, hundreds or even thousands. Trying
to visualize or model such high-dimensional data is incredibly difficult. Often, many of these
features are redundant or correlated. For example, in a dataset about houses, features like
”square footage” and ”number of bedrooms” are likely to be highly correlated.
    Principal Component Analysis (PCA) gives us a way to tackle this complexity. Its core idea
is to change the coordinate system in which we view our data. Instead of using the original
feature axes, PCA finds a new set of axes, called principal components, that are better
aligned with the ”shape” of the data cloud.

    What makes these new axes ”better”?

      1. They capture the maximum variance: The first principal component (PC1) is
         a line drawn through the data that captures the most possible variation. The second
         principal component (PC2) is perpendicular to the first and captures the next most
         variation, and so on.

      2. They are uncorrelated: Each principal component is orthogonal (at a right angle)
         to the others, meaning the new ”features” are not redundant.

     By using only the first few principal components, we can often represent the data in a much
lower-dimensional space while losing very little of the essential information (i.e., the variance).
This makes PCA a powerful tool for dimensionality reduction, data visualization, and noise
filtering.


2     Developing the Mathematical Intuition: From Variance to
      Eigenvectors
The entire method of PCA is born from a single, clear goal: find the direction in the data
with the most ”spread” or variance. Let’s walk through how this goal mathematically leads us
directly to the concepts of covariance matrices and eigenvectors.

2.1    1. The Goal: Maximizing Variance
Let’s formalize our setup. Our data is a matrix X of size n × d, where n is the number of data
points and d is the number of features. The first step, which is crucial, is to mean-center the
data by subtracting the mean of each feature. We’ll call this centered data matrix X̂.
   We are looking for a direction in our d-dimensional space. Any direction can be represented
by a unit vector u (with dimension d × 1). We use a unit vector because we only care about
the direction, not its magnitude, so we enforce the constraint that uT u = 1.

2.2    2. How to Measure Variance in a Specific Direction?
To find the variance of our data along the direction u, we first need to project each data point
(each row of X̂) onto this direction. The projection of a single data point x̂i (a row vector) onto
the direction vector u is given by the dot product: x̂i u.
    If we do this for all n data points, we get a new vector of projected values: P = X̂u. This
vector P is of size n × 1, and it represents our entire dataset transformed into a single dimension
along the direction u.
    Now, we calculate the variance of this new 1D dataset, P . Since the data was mean-centered,
the variance is simply the average of the squared values (with a factor of n − 1 for the sample

2.4   4. Connecting to Eigendecomposition
Our problem has now been transformed into a formal optimization problem:

                            maximize     uT Cu subject to uT u = 1
                                u

This is a classic constrained optimization problem that can be solved using Lagrange multipliers.
The solution reveals that the vectors u that maximize this expression are the eigenvectors of
the matrix C.
   Let’s see why. The equation for an eigenvector v and eigenvalue λ of a matrix C is:

                                              Cv = λv

Now, let’s pre-multiply both sides by v T :

                                     v T Cv = v T (λv) = λ(v T v)

Since eigenvectors are chosen to be unit vectors, we have v T v = 1. This leaves us with:

                                              v T Cv = λ

This is the punchline! This equation tells us that the variance of the data projected onto
an eigenvector v is simply its corresponding eigenvalue λ. To find the direction of maximum
variance, we just need to find the eigenvector of the covariance matrix that has the largest
eigenvalue. This is the first principal component.

of maximizing variance. This leads to one of two equivalent ways to frame the core optimization
problem.

3.1    Perspective 1: Maximizing Variance
    • The Optimization Problem:
                                  maximize          uT Cu subject to uT u = 1
                                       u

The solution is that the optimal vectors u are the eigenvectors of the covariance matrix C.
