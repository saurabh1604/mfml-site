1 Solve one right now, before any theory
Put a wall in front of gradient descent and the answer moves onto the wall. That single
fact drives this whole session.

Here is a problem you can do in your head. Find the smallest value of f ( x ) = x2 , but you are
only allowed to pick x ≥ 2.
Try it. The bowl x2 has its bottom at x = 0. That point is banned. So you slide as close to it as
the rule lets you. That is x = 2, giving f = 4.
Now notice three things about what you just did.

1. The free answer, x = 0, was thrown away. The rule changed the answer.

2. The new answer sat exactly on the edge of the allowed set.

3. At x = 2 the slope of f is 4, not 0. The usual “set the derivative to zero” test fails here.

Point 3 is the reason this session exists. Every method you have learnt so far hunts for a zero
gradient. With a rule in the way, the winning point can have a non-zero gradient. We need a
new test. That test is called KKT, and by the end of this reader you will be able to run it.

2 The standard form: one shape for every problem
Every constrained problem is rewritten as “minimise f , subject to e = 0 and g ≤ 0”.
Two lines of algebra get any problem into that shape.

A constrained optimization problem has an objective (the thing you want smallest) and
constraints (the rules you must obey). We always write it in one fixed layout, called the
standard form:



                                      min     f (x)
                                        x
                                subject to    e(x) = 0
                                              gi (x) ≤ 0,      i = 1, . . . , m                              (1)

Read the symbols one at a time.

 • x (bold x) is the whole list of unknowns, such as ( x, y) or ( β 1 , . . . , β p ).

 • f (x) is the objective function: the score we want as small as possible. We will call it the
   score.

 • e(x) = 0 is an equality constraint. It is a rule you must sit exactly on. We will call it the
   path. Most exam problems have just one.

 • gi (x) ≤ 0 are the inequality constraints. Each one is a wall you must stay behind. We will
   call each one a fence. There can be many, so we number them i = 1, . . . , m.

2.1 Turning any rule into standard form
Your problem will rarely arrive in this shape. Two moves fix that.
Move 1: flip a ≥ into a ≤. Multiply both sides by −1 and the arrow turns around:

                                  h(x) ≥ 0        ⇐⇒         −h(x) ≤ 0.

So x ≥ 0 becomes − x ≤ 0. Same rule, standard shape.
Move 2: move everything to the left. A rule like x + y ≤ 1 becomes x + y − 1 ≤ 0. A rule like
x + y = 1 becomes x + y − 1 = 0.

      ✎ Worked example: Rewrite one problem in standard form
   Take the problem: minimise x2 + y2 subject to x + y = 1, x ≥ 0 and y ≥ 0.
   Step 1.      The score is already fine: f ( x, y) = x2 + y2 .
   Step 2.      The path: x + y = 1 becomes e( x, y) = x + y − 1 = 0.
   Step 3.      First fence: x ≥ 0 becomes g1 ( x, y) = − x ≤ 0.
   Step 4.      Second fence: y ≥ 0 becomes g2 ( x, y) = −y ≤ 0.
   So we have one path and two fences, m = 2. That is the whole conversion.

      ✗ Watch out
   When you flip x ≥ 0 into − x ≤ 0, the constraint function is g1 = − x, not x. Later you will
   need ∇ g1 = (−1, 0), with the minus sign. Getting this sign wrong flips the sign of the
   fine rate and breaks the whole answer.


2.2 Why we never write a strict <
Look at the list again. You see =, ≤ and ≥. You never see < or >. There is a good reason.
Try to minimise f ( x ) = x subject to x > 2. Is x = 2.1 the answer? No, because 2.01 is allowed
and smaller. Is 2.01 the answer? No, because 2.001 is allowed and smaller. You can keep going
forever.
The values get closer and closer to 2, but 2 itself is banned. So there is no smallest allowed
value. The problem has no answer at all.
With x ≥ 2 the endpoint is allowed, so the answer is x = 2, and f = 2. Including the boundary
is what makes the answer exist.




Figure 2: How to read it: the dashed red line is the banned edge x = 2. The amber dots are

      ✽ Wait — really?
   This is not a small technical point. It is the reason the answer lands on the boundary so
   often. Most constrained answers sit exactly on a fence, so a form that excludes the fence
   would throw the answer away.


      ✓ Key takeaway
   Standard form is: minimise f , subject to e = 0 and every gi ≤ 0. Flip a ≥ by multiplying
   by −1. Never use a strict <.

3 You have been doing this since ridge regression
Ridge and lasso are constrained problems in disguise. The penalty term you already
write is the Lagrangian of a fence on the coefficients.

Before the theory, here is where you have already met this shape.
Ridge regression is usually taught as: minimise the mean squared error plus a penalty. Its
honest original form is a constrained problem:
                                                        n
                                    min    MSE = n1 ∑ (yk − ŷk )2
                                      β
                                                      k =1
                                            p
                              subject to   ∑ β2j ≤ s.                                                   (2)
                                           j =1

Here β j is the coefficient on feature j, and s is a budget you choose. Lasso regression is the
same, with ∑ j | β j | ≤ s instead.
Read (2) in the park story. The score is the training error. The fence is a budget on how big the
coefficients may grow.

3.1 Why we fence the coefficients at all
Without gradient descent, linear regression solves for the coefficients in one shot:

                                      β̂ = ( X ⊤ X )−1 X ⊤ y,

where X is the feature matrix and y is the output vector. The inverse is the weak spot. An
inverse is the adjoint divided by the determinant. When the determinant is near zero, the
entries of the inverse blow up.
The determinant goes to zero when two feature columns carry the same information. Say x2 is
exactly twice x1 :
                                       
                     ⊤              2 4
                   X X = A =              ,     det A = 2 · 8 − 4 · 4 = 0.
                                    4 8

The rank is 1, not 2, so A−1 does not exist. Real data is rarely this perfect, but with strong
multicollinearity (features that move together) the determinant gets tiny. Then the coefficients
explode. This is called parameter inflation. A true relationship like

                                    y = 0.2x1 + 4x2 − 0.6x3

can come back fitted as
                                  ŷ = 200x1 − 180x2 + 0.79x3 .
The two big numbers nearly cancel. The fit looks fine on the training data and falls apart on
new data.

4 The one picture: at the answer, two arrows lie on one line
Where the walk stops, the gradient of the score and the gradient of the fence point along
the same line. That single geometric fact becomes the first KKT condition.

Go back to the park. You are walking downhill and you hit the fence. Why do you stop here
and not slide further along it?
Because sliding along the fence no longer takes you downhill. At the stopping point, the
downhill direction of the score points straight into the fence. There is no piece of it left that
runs along the fence.
Say that with gradients. The gradient ∇ f points uphill on the score. The gradient ∇ g points
out of the allowed side of the fence. “No downhill left along the fence” means these two
arrows lie on one line:
                              ∇ f ( x ⋆ ) = − µ ∇ g ( x ⋆ ), µ ≥ 0.                       (3)

      ✗ Watch out
   The two arrows are parallel, not equal. They almost never have the same length. The
   number µ is the stretch factor between them. Saying “∇ f = ∇ g” is the single most
   common slip on this topic.


      ☞ The intuition
   Break ∇ f into two pieces: one along the fence, one across it. If the along-the-fence piece
   is not zero, you can still walk downhill, so you are not finished. You stop only when that
   piece vanishes. Then all of ∇ f points across the fence, which is what (3) says.


      ✓ Key takeaway
   At the winning point, the score’s gradient and the fence’s gradient are parallel. The
   stretch factor between them is the fine rate.

5 The Lagrangian: turn every fence into a fine
Add each broken rule to the score, priced by a fine rate. The rules disappear from the
problem and reappear inside one unconstrained function.

We know how to optimise a function with no rules: take derivatives, set them to zero. So the
plan is to remove the rules. The way to remove a rule is to charge for breaking it.
Build one new function, the Lagrangian:
                                                             m
                              L(x, λ, µ) = f (x) + λ e(x) + ∑ µi gi (x).                                 (4)
                                                            i =1


Reading it in plain words: the total bill equals the score, plus a fine for leaving the path, plus a
fine for crossing each fence.
The new symbols are the Lagrange multipliers, also called the fine rates:

 • λ (the Greek letter lambda) is the fine rate for the path.

 • µi (the Greek letter mu) is the fine rate for fence i.

      ⋆ Everyday picture
   A guard stands at the fence. Cross it and you pay µ rupees per metre past it. Stay behind
   it and you pay nothing. The guard would love you to stray, so the guard sets the fine as
   high as it can go. You want your bill low. That tug-of-war is the whole method.


5.1 The sign rules, and why they are not arbitrary
Two rules govern the fine rates. They look small and they decide everything.
Rule A: λ is free. It may be positive, negative or zero. The path constraint is e(x) = 0. You
can drift off it in either direction. Both directions are equally illegal, so the fine has no natural
sign. We check this with real numbers in Section 10.
Rule B: every µi must satisfy µi ≥ 0. Here is the argument. A fine has to raise your bill.
Suppose you cross fence i, so gi (x) > 0. The term added is µi gi . If µi were negative, that
term would be negative. Crossing the fence would lower your bill. The optimiser would then
run straight out of bounds, on purpose. Forcing µi ≥ 0 blocks that. This rule is called dual
feasibility.

      ✗ Watch out
   Do not carry Rule A over to a fence. For an inequality, a negative µi does not mean “a
   different sign convention”. It means the case you are testing is impossible, and you throw
   it away. You will use this to kill three of four cases in Section 9.


      ✓ Key takeaway
   The Lagrangian is score + fine for the path + fines for the fences. The path fine has any
   sign. Every fence fine must be zero or positive.

6 The slack variable: how ≤ becomes =
Add a squared number to soak up the leftover room. A squared number is never negative,
so the new equation says exactly what the old inequality said.

The Lagrangian in (4) treats the fence like the path. But they are not the same. The path is an
equation. The fence is an inequality. Derivatives handle equations well and inequalities badly.
So we convert the fence into an equation. Take the fence gi (x) ≤ 0 and add a new unknown ti :

                                                    gi (x) + t2i = 0.                                              (5)

The number ti is a slack variable. Read it as the room you have left before you touch fence i.
Check that (5) really says the same thing. Rearranging, t2i = − gi (x). A square is never negative,
so − gi (x) ≥ 0, which is gi (x) ≤ 0. That is the original fence, back again. Nothing was lost and
nothing was added.

      ☞ The intuition
   Why square it, instead of writing gi + ti = 0 with ti ≥ 0? Because then we would still be
   carrying an inequality, ti ≥ 0. The square builds “never negative” into the algebra itself.
   It also keeps the Lagrangian smooth, so we can differentiate it.


Now rewrite the Lagrangian with the slack terms folded in:
                                                                 m
                                L(x, λ, µ, t) = f (x) + λ e(x) + ∑ µi gi (x) + t2i .
                                                                                 
                                                                                                                   (6)
                                                                   i =1

Every rule in the problem is now an equation. There are no inequalities left, apart from the
sign rule µi ≥ 0.

6.1 Count the unknowns
It pays to know how many things you are solving for.

                    Unknown            How many       What it is
                    x                  n              the variables you actually care about
                    λ                  1              the fine rate for the path
                    µ1 , . . . , µ m   m              one fine rate per fence
                    t1 , . . . , t m   m              one room-left number per fence
                    Total              n + 2m + 1

Books that skip slack variables report n + m + 1 instead. Both counts are right. They just
describe different setups. We keep the slacks for two more pages, because they hand us the
next result for free.

      ✓ Key takeaway
   A slack variable is a squared number that fills the gap to the fence. It turns gi ≤ 0 into
   gi + t2i = 0 with no loss.

7 Complementary slackness, derived in four lines
Differentiate the Lagrangian with respect to the room-left variable. Out drops the rule
that a fine and spare room can never both be present.

This is the result most books state and never prove. With the slack variable in hand, the proof
is four lines.
Differentiate (6) with respect to ti . The only term containing ti is µi t2i :

                                           ∂L
                                               = 2µi ti = 0.                                                 (7)
                                           ∂ti

Multiply both sides by ti and halve:

                                               µi t2i = 0.                                                   (8)

From (5) we know t2i = − gi (x). Substitute:

                                                                µ i gi ( x ⋆ ) = 0
                                        
                          µ i − gi ( x ) = 0      =⇒                                                         (9)


That boxed line is complementary slackness. The name now makes sense: it is the statement
about slack, and it was derived from the slack variable.

7.1 What it actually says
A product of two numbers is zero only when at least one of them is zero. So for each fence i,
exactly one of these two worlds holds.
World 1: you have room to spare. Here gi (x⋆ ) < 0. You are strictly inside the fence. The guard
has no grounds to charge you, so µi = 0. The fence is not doing any work. We say the fence is
inactive, or slack.
World 2: you are touching the fence. Here gi (x⋆ ) = 0. You are pressed against the edge. Now
the fine rate is allowed to be positive, and usually is: µi > 0. The fence is holding you back.
We say the fence is active, or tight.

      ✗ Watch out
   Two traps here, and both are easy to fall into.
   Trap 1. “The fence is active” and “we are on the boundary” are the same world, not two
   different ones. Active means gi = 0, which means on the boundary. The real split is: fine
   is zero versus fence is touched.
   Trap 2. On the boundary the fine rate is not forced to zero. With gi = 0 the product µi gi
   is zero for any µi . In Section 11 you will meet a problem whose answer sits on the fence
   with µ = 4. A positive fine on an active fence is the normal case, not an error.


      ✽ Wait — really?
   The fine rate is not a bookkeeping device. It is a price. It measures how much the best
   score would improve if the fence were relaxed a little. Relax it by a small amount ε and
   the best score falls by about µε. A fence with µ = 0 is a fence you would pay nothing to
   remove, because it was never in your way.

8 The five KKT conditions
Differentiate the Lagrangian once with respect to every unknown, add the sign rule on
the fines, and you have the full test for a constrained optimum.

The conditions are named after Karush, Kuhn and Tucker, so KKT. They are not a new idea.
They are the old idea — set every derivative to zero — run on (6).
Work through the unknowns one at a time.

8.1 Condition 1: stationarity (from ∂L/∂x)
Differentiate with respect to the n real variables. The slack terms t2i do not contain x, so they
drop out:
                                                                 m
                                ∇ f (x⋆ ) + λ ∇e(x⋆ ) + ∑ µi ∇ gi (x⋆ ) = 0.                                          (10)
                                                                i =1

This is n equations, one per variable. It is the arrows-on-one-line picture from (3), now written
for many rules at once.

8.2 Condition 2: primal feasibility, path (from ∂L/∂λ)
Only the term λe(x) contains λ, and it is linear in it. So the derivative is just e(x):

                                                     e(x⋆ ) = 0.                                                      (11)

This is the path constraint, handed back to us. That is a good sign: the machine did not lose
our rules.

8.3 Condition 3: primal feasibility, fences (from ∂L/∂µi )
Only µi [ gi + t2i ] contains µi , so

                            gi (x⋆ ) + t2i = 0        =⇒               gi (x⋆ ) = −t2i ≤ 0.

So
                                         gi (x⋆ ) ≤ 0,          i = 1, . . . , m.                                     (12)
Again, our own fences returned to us.

8.4 Condition 4: complementary slackness (from ∂L/∂ti )
This is the result we proved above:

                                        µi gi (x⋆ ) = 0,         i = 1, . . . , m.                                    (13)

8.5 Condition 5: dual feasibility (the sign rule)
                                           µi ≥ 0,         i = 1, . . . , m.                                          (14)
No derivative gives you this one. It came from Rule B: a fine must raise the bill, never lower it.
Note that λ is not in this list. It stays free.

       ✗ Watch out
     You will see KKT quoted as “four conditions” in some notes and “five” in others. The
     four-item version folds µi ≥ 0 into the setup instead of listing it. Nothing changes. Count
     five when you write an exam answer, so no marker can say you missed a check.

8.6 How many cases will you test?
Condition (13) is one product per fence. Each product offers two branches: the fine is zero, or
the fence is touched. The branches multiply:
                                    number of cases = 2m .
So m = 1 gives 2 cases, m = 2 gives 4, m = 3 gives 8, and m = 4 gives 16.

      ✗ Watch out
   It is easy to guess m2 instead of 2m . They agree at m = 2 (both give 4) and at m = 4 (both
   give 16), which hides the mistake. They disagree at m = 3: the true count is 23 = 8, not 9.
   Always double the count for each new fence.


Three things about that count are worth knowing before you rely on it.
Equality constraints do not branch. The path is always tight, and λ is never forced to zero. So
e(x) = 0 adds no cases. Only the fences do.
The branches overlap. A point can have both µi = 0 and gi = 0 at once. That is the degenerate
case, and it will show up in two different branches. So the 2m cases cover everything, but they
are not a clean split. Finding the same point twice is normal.
It counts cases, not answers. A branch may give no solution, exactly one, or a whole family. In
Section 9 one branch dies on arithmetic before any fine rate is computed. So 2m is the number
of branches you must check, not the number of candidates you will collect.

      ✽ Wait — really?
   2m grows fast. Ten fences give 1024 branches, and a support vector machine has one fence
   per training point. That is why nobody solves a real SVM by listing cases. You solve the
   dual instead, which is Section 11. The case list is an exam tool, not an algorithm.


8.7 When is the KKT test trustworthy?
Two honest limits belong with the five conditions. Both are usually left out. First, some
vocabulary. Necessary means every true answer must pass the test. Sufficient means anything
that passes the test is a true answer. KKT is not automatically either one.
KKT is necessary only if the constraints are well behaved at the answer. The technical name
is a constraint qualification. The common one is: the gradients of the active constraints at x⋆
must be linearly independent. Two active fences with parallel gradients break that. Then the
multipliers may not exist at all, and the test can miss the true answer. Every problem in this
reader passes, and so will your exam problems.
KKT is sufficient only if the problem is convex. A point that passes all five checks is a KKT
point. For a convex problem — convex f , convex gi , linear e — a KKT point is the global
minimum, full stop. For a non-convex problem it may be a maximum or a saddle, so you must
check it a second way.

      ✗ Watch out
   Do not write “all five conditions hold, so this is the minimum” unless the problem is
   convex. Say which part is convex, or verify the point another way. Section 10 shows both
   routes on a non-convex constraint.

9 Worked example: one path, two fences
We run all five KKT conditions on a problem with three rules, test all four cases, and
reject three of them on signs alone.


      ✎ Worked example: Minimise f ( x, y) = x2 + 2y2 subject to x + y = 1, x ≥ 0, y ≥ 0

   Step 1.      Standard form. The score is f = x2 + 2y2 . The path is e = x + y − 1 = 0. The
                fences are g1 = − x ≤ 0 and g2 = −y ≤ 0. So m = 2, and we expect 22 = 4
                cases.
   Step 2.      Write the Lagrangian. Using (4):

                            L( x, y, λ, µ1 , µ2 ) = x2 + 2y2 + λ( x + y − 1) − µ1 x − µ2 y.

                The minus signs come from g1 = − x and g2 = −y. There are five unknowns.
                                     ∂L

11 Primal and dual: the same game, played in a different order
You and the guard both move. If you move first you are solving the primal. If the guard
moves first you are solving the dual. The order changes the value, and never in your
favour.

Look at the Lagrangian once more, for a single fence:
                              L( x, µ) = f ( x ) + µ g( x ),       µ ≥ 0.
Two players share this one number. You pick x and want the bill low. The guard picks µ and
wants the bill high. That is a two-player, zero-sum game, the kind John Nash studied.
Now ask: who moves first?

11.1 The primal: you move first
If you pick x first, the guard sees your choice and answers with the worst µ for you. So the
value of picking x is maxµ≥0 L( x, µ), and your best play is
                                    p⋆ = min max L( x, µ).                                                  (16)
                                              x     µ ≥0

This is the primal problem. It is a min-max.
Here is why (16) is the original problem in disguise. Suppose you pick an x that breaks the
fence, so g( x ) > 0. The guard then raises µ without limit, and the inner maximum is +∞. Any
illegal x scores infinity, so you will never choose one. Suppose instead you obey the fence,
so g( x ) ≤ 0. The best the guard can do is µ = 0, and the value is just f ( x ). So the min-max
quietly rules out every illegal point and scores every legal one by its true score.

11.2 The dual: the guard moves first
Swap the order. The guard announces a fine rate µ, then you pick your best x knowing that
price:
                               d⋆ = max min L( x, µ).                                 (17)
                                             µ ≥0        x

This is the dual problem, a max-min. The inner part,
                                      d(µ) = min L( x, µ),
                                                    x
is called the dual function. It has one input per fine rate, and no x at all.

      ⋆ Everyday picture
   Announcing the price first is a worse deal for the guard. You get to see the number and
   plan around it. Moving second is an advantage, and the guard loses it. That is the whole
   reason d⋆ can only fall short of p⋆ .


11.3 Weak duality, strong duality, and the gap
Moving second is never worse, so the guard’s value cannot beat yours:
                                              d⋆ ≤ p⋆ .                                                     (18)
This always holds, for any problem at all. It is called weak duality. The shortfall p⋆ − d⋆ ≥ 0
is the duality gap.
When the gap is zero, so d⋆ = p⋆ , we have strong duality. This happens for convex problems
that have a strictly feasible point, which covers ridge, lasso and the support vector machine.



WILP, BITS Pilani                                   25
MFML Companion · AIMLCZC416                                Constrained Optimization · Lagrangian, KKT & Duality


      ✗ Watch out
   Say it in the right direction. For a minimisation primal, the dual sits below: d⋆ ≤ p⋆ . A
   positive gap is not “weak duality” as a special case of equality — weak duality is the
   inequality itself, and it is always true. Strong duality is the extra fact that the two meet.


11.4 Why anyone bothers
Three reasons, and the third is the one that matters in machine learning.
One: fewer unknowns. The primal has n variables. The dual has one per constraint. Swap a
10-variable primal for a 1-variable dual and the work collapses.
Two: the dual is always concave. Fix any x. Then L( x, µ) = f ( x ) + µ g( x ) is a straight line in
µ, with height f ( x ) and slope g( x ). The dual d(µ) is the lowest of all those lines, one line per
x. The lowest of a bundle of straight lines always bends downward, so d is concave. This holds
even when f is not convex. So maximising d is a well-behaved problem with no local traps.
Three: the dual can change what the variables mean. In the support vector machine, the
primal is over the weight vector, whose length is the number of features. The dual is over one
µi per training point. That swap is what lets kernels enter, and it is why we spent this session
here.

      ✗ Watch out
   “The dual is convex” is loose talk. The dual function is concave. The dual problem —
   maximise a concave function — is a convex optimization problem. Both statements are
   right, and they are about different objects.

   9. Dual (if wanted)               d(λ, µ) = minx L; then maximise d over λ free, µi ≥ 0.
   10. Duality check                 d⋆ ≤ p⋆ always. Equal means strong duality.
   11. Say why it wins               Convex problem ⇒ the KKT point is the global minimum.
                                     Not convex ⇒ verify a second way.

14.2 Symbol cheat sheet

                Symbol          Meaning
                x               the list of n variables you are solving for
                f (x)           the objective; the number to make small
                e(x)            the equality constraint function; some books write h
                gi ( x )        inequality constraint i, written so that gi ≤ 0
                m               how many inequality constraints there are
                λ               multiplier on the equality; any sign
                µi              multiplier on inequality i; must satisfy µi ≥ 0
                ti              slack variable for fence i, with t2i = − gi
                L               the Lagrangian
                ∇f              gradient of f ; the vector of partial derivatives
                p⋆              the primal optimal value
                d⋆              the dual optimal value
                p⋆ − d⋆         the duality gap; always ≥ 0
                ⋆ superscript   marks an optimal value, as in x ⋆


      ✓ Key takeaway
   Fences move the answer onto the boundary. The Lagrangian prices each fence. KKT is
   just “all derivatives zero” plus a sign rule. Complementary slackness comes from the
   slack variable, and it says a fine and spare room never appear together. The dual reorders
   the game and never overshoots.
