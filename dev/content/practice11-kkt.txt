1 Read this first: the toolkit
Four recipes solve every problem in this set. Everything else is careful bookkeeping.

Standard form. Before doing anything, rewrite the problem as a minimization in standard
form:

          min f ( x )    subject to      gi ( x ) ≤ 0 (i = 1, . . . , m),      h j ( x ) = 0 ( j = 1, . . . , p).
            x

The conversion rules are mechanical: a maximization max f becomes min (− f ); a constraint
a ≥ b becomes b − a ≤ 0; an equality h = c becomes h − c = 0.

      ☞ The intuition
   Everything in this topic answers one question: at the best feasible point, how does the objective’s
   gradient relate to the constraints’ gradients? Lagrange multipliers are the bookkeeping device
   that records that relationship — one multiplier per constraint, measuring how hard that
   constraint “pushes”.


Recipe 1 — Lagrange (equality constraints only). To optimize f ( x ) subject to h( x ) = 0: at a
constrained optimum the two gradients are parallel,

                                       ∇ f ( x ) = λ ∇ h ( x ),       h( x ) = 0.

Solve these equations together. With several equality constraints h1 = · · · = h p = 0, the
condition becomes ∇ f = λ1 ∇h1 + · · · + λ p ∇h p . The sign of λ is unrestricted here — an
equality constraint can push either way.

Recipe 2 — KKT (the full set of conditions). For the standard form above, build the Lagrangian
                                                      m                 p
                           L( x, µ, λ) = f ( x ) + ∑ µi gi ( x ) + ∑ λ j h j ( x ).
                                                     i =1              j =1

A point x ⋆ with multipliers (µ⋆ , λ⋆ ) satisfies the KKT conditions when all four hold:

  K1. Stationarity: ∇ x L( x ⋆ , µ⋆ , λ⋆ ) = 0.

  K2. Primal feasibility: gi ( x ⋆ ) ≤ 0 for all i, and h j ( x ⋆ ) = 0 for all j.

  K3. Dual feasibility: µi⋆ ≥ 0 for all i.

  K4. Complementary slackness: µi⋆ gi ( x ⋆ ) = 0 for every i.

For a convex problem (convex f and gi , affine h j ), any point satisfying K1–K4 is a global minimizer
— KKT is sufficient. Under a constraint qualification such as Slater’s condition, KKT is also
necessary.
Recipe 3 — the complementary-slackness case method. Condition K4 says every inequality
constraint is in one of two states: inactive (µi = 0, the constraint exerts no force) or active
(gi ( x ⋆ ) = 0, the point sits on the boundary). With m inequalities there are at most 2m active/in-
active patterns. Pick a pattern, solve K1 together with the assumed active equations, then check
what the pattern did not enforce: feasibility of the constraints assumed inactive, and µi ≥ 0 for
the constraints assumed active. Exactly the patterns that pass every check survive.
Recipe 4 — Lagrangian duality. From the same Lagrangian, define the dual function by
minimizing over x with the multipliers held fixed:

                                         q(µ, λ) = inf L( x, µ, λ).
                                                       x

This inner minimization is unconstrained — that is the whole point. The dual problem is
maxµ≥0, λ q(µ, λ), and it is always concave. Writing p⋆ for the primal optimum and d⋆ for the
dual optimum: weak duality d⋆ ≤ p⋆ holds for every problem; strong duality d⋆ = p⋆ holds
for convex problems satisfying Slater’s condition (some strictly feasible point exists, gi ( x̃ ) < 0
for all i). Under strong duality, the primal solution is recovered from the inner minimization
evaluated at the optimal multipliers.

      ✗ Watch out
   KKT as written above is for minimization with ≤ constraints. Applying it to a maximiza-
   tion, or to a ≥ constraint, without converting first is the single most common source of
   sign errors in this topic. Convert to standard form before writing the Lagrangian — always.
   Problems 7, 9 and 10 drill exactly this.

2 Part A — Framing problems and the Lagrange condition

      ☞ Problem 1 · Framing a word problem, then solving it
   A farmer has 20 metres of fencing and wants to enclose a rectangular plot of the largest
   possible area.
   (a) Frame this as a constrained optimization problem: name the decision variables, the
       objective, and the constraint.
   (b) Solve it with a Lagrange multiplier.
   Skill trained: translating words into max f subject to h = 0, then applying Recipe 1.


Solution



Step 1.     Name the variables. Let x > 0 be the width and y > 0 the height of the plot, both in
            metres.

Step 2.     Write the objective. The area is A( x, y) = xy, and we want it as large as possible:
            maxx,y xy.

Step 3.     Write the constraint. The perimeter uses all the fencing: 2x + 2y = 20. Dividing by 2
            gives the cleaner equivalent h( x, y) = x + y − 10 = 0. The framed problem is

                                       max xy         subject to       x + y = 10.
                                        x,y


Step 4.     Write the Lagrange condition. ∇ f = λ∇h with f = xy and h = x + y − 10. The
            gradients are ∇ f = (y, x ) and ∇h = (1, 1), so

                                                     y = λ · 1 = λ,
                                                     x = λ · 1 = λ.

Step 5.     Solve the system. Both equations say the same thing: x = y = λ. Substitute into the
            constraint:
                                x + y = 10 =⇒ λ + λ = 10 =⇒ λ = 5.
            So x = 5 and y = 5: the optimal plot is a square.

Step 6.     Confirm it is a maximum. On the constraint line, y = 10 − x and the area becomes
            A( x ) = x (10 − x ) = 10x − x2 , a downward parabola. Its only critical point is the top,
            and at the endpoints (x → 0 or x → 10) the area collapses to 0. So x = y = 5 is the
            maximum, with A = 5 × 5 = 25.

      ✓ Final answer
   Decision variables x, y; objective max xy; constraint x + y = 10. Optimum: x ⋆ = y⋆ = 5 m
   (a square), maximum area A⋆ = 25 m2 , multiplier λ⋆ = 5.

      ☞ Problem 2 · Geometry of the Lagrange condition
   Find the point on the line x + y = 4 that is closest to the origin, by minimizing f ( x, y) =
   x2 + y2 subject to x + y = 4. Then explain, in one sentence, what ∇ f = λ∇h means

Step 1.     Set up the condition. Here f = x2 + y2 and h = x + y − 4, so ∇ f = (2x, 2y) and

                                                            2x = λ,
                                                            2y = λ.

Step 2.     Eliminate λ. Subtracting the two equations: 2x − 2y = 0, so x = y.

Step 3.     Use the constraint. x + y = 4 with x = y gives 2x = 4, so x = 2 and y = 2. Then
            λ = 2x = 4.

            the origin to the line x + y = 4 is |−4|/ 1 + 1 = 4/ 2 = 2 2, and (2 2) = 8.

Step 5.     Read the geometry. At (2, 2) the level curve of f (the circle x2 + y2 = 8) just touches
            the line: the circle is tangent to the constraint. Tangency is exactly the statement that
            the two gradients point along the same direction — ∇ f = (4, 4) = 4 · (1, 1) = λ∇h.

   If ∇ f had any component along the constraint line, you could slide along the line in that
   direction and improve f — so at the optimum, no such component can remain. That forces
   ∇ f to be perpendicular to the line, i.e. parallel to ∇h. This one picture is the entire logic
   of Lagrange multipliers.

      ☞ Problem 3 · The multiplier is a shadow price
   A workshop produces Q( x, y) = xy units using x machine-hours (cost Rs. 2 per hour) and
   y labour-hours (cost Rs. 1 per hour). The budget is Rs. 8.
   (a) Frame and solve: how should the budget be split to maximize output?
   (b) Interpret the multiplier λ. Then re-solve with a budget of Rs. 9 and check the interpre-
       tation numerically.
   Skill trained: framing with costs, and reading λ as “extra objective per extra unit of budget”.



Solution



Step 1.     Frame. Maximize Q = xy subject to the budget constraint 2x + y = 8, with x, y > 0.

Step 2.     Lagrange condition. ∇ Q = (y, x ) and, for h = 2x + y − 8, ∇h = (2, 1). So ∇ Q =
            λ∇h reads

                                                            y = 2λ,
                                                            x = λ.

Step 3.     Eliminate λ. From the second equation λ = x; substitute into the first: y = 2x. In
            words: at the optimum, spend the same amount on each input (2x rupees on machines
            equals y · 1 = 2x rupees on labour).

Step 4.     Use the budget. 2x + y = 8 with y = 2x:

                                   2x + 2x = 8 =⇒ 4x = 8 =⇒ x = 2,                  y = 4.

            Output Q = 2 × 4 = 8, and λ = x = 2.

Step 5.     Interpret λ. The multiplier is the shadow price of the budget: one extra rupee of
            budget buys approximately λ = 2 extra units of output.

Step 6.     Check with budget 9. Redo Step 4 with 2x + y = 9 and y = 2x: 4x = 9, so x = 9/4,
            y = 9/2, and
                                               9 9    81
                                           Q= · =        = 10.125.
                                               4 2     8
            The gain is 10.125 − 8 = 2.125, close to λ = 2 as predicted. (In general x = b/4,
            y = b/2, so Q(b) = b2 /8 and dQ/db = b/4 = 2 at b = 8 — exactly λ. The prediction
            is exact in the derivative and approximate over a whole-rupee jump.)

      ✓ Final answer
   x ⋆ = 2 machine-hours, y⋆ = 4 labour-hours, Q⋆ = 8 units, λ⋆ = 2. The multiplier is the
   marginal value of budget: dQ⋆ /db = λ.

      ✽ Wait — really?
   The multiplier you computed as a mere “helper variable” turns out to be a forecast: it
   predicts how much the optimal objective improves per unit of constraint relaxation —
   before you re-solve anything. This is why economists call it a price, and why in ML the
   multipliers on data constraints tell you which data points matter (Problem 15 makes this
   literal).


      ☞ Problem 4 · Two equality constraints at once
   Minimize f ( x, y, z) = x2 + y2 + z2 subject to

                            h1 : x + y + z = 3        and       h2 : x − y = 0.

   Skill trained: running Recipe 1 with two multipliers: ∇ f = λ1 ∇h1 + λ2 ∇h2 .



Solution



Step 1.     Write the condition with two multipliers. With ∇ f = (2x, 2y, 2z), ∇h1 = (1, 1, 1)
            and ∇h2 = (1, −1, 0), the condition ∇ f = λ1 ∇h1 + λ2 ∇h2 reads

                                                    2x = λ1 + λ2 ,
                                                    2y = λ1 − λ2 ,
                                                    2z = λ1 .

Step 2.     Use the second constraint. h2 says x = y. Subtract the second equation from the first:

                                     2x − 2y = (λ1 + λ2 ) − (λ1 − λ2 ) = 2λ2 .

            The left side is 0 (because x = y), so λ2 = 0.

Step 3.     Simplify. With λ2 = 0 the three equations collapse to 2x = 2y = 2z = λ1 , i.e.
            x = y = z = λ1 /2.

Step 4.     Use the first constraint. x + y + z = 3 with all three equal gives 3x = 3, so x = y =
            z = 1 and λ1 = 2x = 2.

Step 5.     Value. f (1, 1, 1) = 1 + 1 + 1 = 3. Since f is a sum of squares (strictly convex) and
            both constraints are affine, this critical point is the unique global minimum.

      ✓ Final answer
   ( x ⋆ , y⋆ , z⋆ ) = (1, 1, 1), f ⋆ = 3, with multipliers λ1⋆ = 2 and λ2⋆ = 0.


      ☞ The intuition
   λ2 = 0 is not an accident. Minimizing distance-to-origin on the plane x + y + z = 3 alone
   already lands on the symmetric point (1, 1, 1), which happens to satisfy x = y for free. A
   constraint that the solution satisfies anyway exerts no force — its multiplier is zero. This

      ☞ Problem 6 · First contact with KKT: active vs. inactive
   Solve the two one-dimensional problems
   (a) min ( x − 3)2     subject to     x ≤ 1;
          x
   (b) min ( x − 3)2     subject to     x ≤ 5.
          x
   For each, write all four KKT conditions explicitly and identify whether the constraint is
   active or inactive at the optimum.
   Skill trained: writing K1–K4 in full, and feeling the difference between a constraint that binds and one that
   does not.


Solution



Part (a).

Step 1.       Standard form. f ( x ) = ( x − 3)2 and g( x ) = x − 1 ≤ 0. Lagrangian: L( x, µ) =
              ( x − 3)2 + µ ( x − 1).

Step 2.       Write the four KKT conditions.

                                             K1 (stationarity):     2( x − 3) + µ = 0
                                      K2 (primal feasibility):      x−1 ≤ 0
                                        K3 (dual feasibility):      µ≥0
                                      K4 (compl. slackness):        µ ( x − 1) = 0

Step 3.       Case µ = 0 (constraint inactive). K1 becomes 2( x − 3) = 0, so x = 3. Check K2:
              3 − 1 = 2 ̸≤ 0. Infeasible — discard this case.

Step 4.       Case x = 1 (constraint active). K1 gives

                                  2(1 − 3) + µ = 0 =⇒ −4 + µ = 0 =⇒ µ = 4.

              Check K3: µ = 4 ≥ 0. ✓ K2 holds (1 − 1 = 0), and K4 holds because g = 0. All four
              conditions pass.

Step 5.       Conclude (a). x ⋆ = 1, µ⋆ = 4, f ⋆ = (1 − 3)2 = 4. The constraint is active: the
              unconstrained minimizer x = 3 lies outside the feasible set, so the solution is pushed
              onto the boundary and the multiplier records the force of that push.

Part (b).

Step 1.       Standard form. Now g( x ) = x − 5 ≤ 0 and L( x, µ) = ( x − 3)2 + µ ( x − 5). The four
              conditions are the same four lines with x − 5 in place of x − 1.

Step 2.     Case µ = 0. K1: 2( x − 3) = 0, so x = 3. Check K2: 3 − 5 = −2 ≤ 0. ✓ Feasible! K3
            holds (µ = 0 ≥ 0) and K4 holds (µ = 0). All four pass — no need to try the other case,
            since the problem is convex and any KKT point is the global minimum.

Step 3.     Conclude (b). x ⋆ = 3, µ⋆ = 0, f ⋆ = 0. The constraint is inactive: the unconstrained
            minimizer already satisfies it, so it exerts no force.

      ✓ Final answer
   (a) x ⋆ = 1, µ⋆ = 4, f ⋆ = 4 — constraint active. (b) x ⋆ = 3, µ⋆ = 0, f ⋆ = 0 — constraint
   inactive.


      ☞ The intuition
   Think of µ as the force the wall exerts on a ball rolling downhill inside the feasible region.
   In (a) the ball wants to reach x = 3 but the wall at x = 1 stops it, pressing back with force
   µ = 4. In (b) the ball settles at x = 3 without ever touching the wall at x = 5, so the wall
   pushes with force 0. Complementary slackness is just: a wall you are not touching cannot
   push you.
