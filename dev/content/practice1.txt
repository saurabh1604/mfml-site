1 Solve one right now
You already know how to do this. The matrix work is only bookkeeping.

Here are two equations:

                                                     x + 2y = 8                                                  (1)
                                                     3x − y = 3                                                  (2)

Multiply (1) by 3 and subtract it from (2). The x term dies:

                (3x − y) − 3( x + 2y) = 3 − 3(8)            =⇒      −7y = −21          =⇒       y = 3.

Put y = 3 back into (1): x + 6 = 8, so x = 2.
That is the whole method. You killed one unknown, solved for the other, then walked backwards.
Everything in this document is that same move, written in a tidier way so it never gets confusing
with five unknowns and four equations.

      ✓ Key takeaway
   Gaussian elimination is one idea: use an equation to delete an unknown from the equations
   below it. Repeat. Then walk back up.

2 Drop the letters: the augmented matrix
The names x, y, z carry no information. Only the numbers matter, so keep only the
numbers.

Take a system of m equations in n unknowns. Write it as Ax = b, where A is the m × n
coefficient matrix, x is the column of unknowns, and b is the column of right-hand sides. For
the warm-up above:                                           
                                   1 2            x              8
                           A=             ,  x=      ,     b=       .
                                   3 −1           y              3

Now glue b onto the right of A as one extra column. That is the augmented matrix, written
[ A | b ]:                                           
                                              1 2 8
                                 [ A | b] =             .
                                              3 −1 3

The vertical bar is only a reminder. It says: columns left of the bar belong to unknowns, the
column right of the bar is the answer side. Row i of the augmented matrix is equation i.

      ⋆ Everyday picture
   Think of a recipe card. “2 cups flour, 3 eggs, 1 cup milk → 12 pancakes” carries the
   same content as “2 f + 3e + 1m = 12”. The words “flour”, “eggs”, “milk” are just column
   headings. Once everyone agrees on the column order, you can throw the headings away
   and keep the row of numbers.


      ✗ Watch out
   Line up your columns before you write the matrix. If an equation is 2y + x = 5, the row is
   [ 1 2 | 5 ], not [ 2 1 | 5 ]. And a missing unknown is a zero, not a blank: x + z = 4 in three
   unknowns is [ 1 0 1 | 4 ].

 3 Three legal moves
 Only three operations are allowed on rows, and each one can be undone. That is why
 the answer never changes.

 An elementary row operation is one of these three:

(R1) Swap. Exchange row i and row j. Written Ri ↔ R j .

(R2) Scale. Multiply a whole row by a nonzero number c. Written Ri → cRi .

(R3) Add a multiple. Replace row i by row i plus c times row j, where i ̸= j. Written Ri →
     Ri + cR j .

 Each move matches a safe move on the equations themselves. Swapping is writing the equations
 in a different order. Scaling is multiplying both sides of one equation by the same nonzero
 number. Adding a multiple is adding one true equation to another true equation.
 Why does the solution set survive? Because every move is reversible. A swap is undone by the
 same swap. Scaling by c is undone by scaling by 1/c, which needs c ̸= 0. Adding cR j is undone
 by adding −cR j . So the new system and the old system have exactly the same solutions. Two
 systems related this way are called row equivalent.

       ✗ Watch out
    Two traps. First, c = 0 is banned in (R2): multiplying a row by zero destroys an equation
    and cannot be undone. Second, in (R3) you may not use row i to change itself; R2 →
    R2 − R2 is not a legal move, it just erases a row.


       ✓ Key takeaway
    Row operations never create or destroy solutions. They only change how the same solution
    set is written.

4 REF: build the staircase
Push zeros into the bottom-left corner until the leading entries form a descending
staircase.

In any nonzero row, the pivot (also called the leading entry) is the first nonzero number as you
read left to right.
A matrix is in row echelon form, or REF, when all three hold:

E1. Every all-zero row sits at the bottom.

E2. The pivot of each row is strictly to the right of the pivot of the row above it.

E3. Everything below a pivot, in that pivot’s own column, is zero.

Condition E2 is what makes the staircase. Each step down moves you at least one column right,
and sometimes more than one.
Here is a matrix in REF, with pivots shown in bold:
                                                         
                                        2    1 −3    4 5
                                       0
                                            0 1     2 −1 
                                                          
                                       0    0 0     5 3 
                                        0    0 0     0 0

The pivots sit in columns 1, 3, 4. Column 2 was skipped, which is allowed. The zero row is at
the bottom, which is required.
A column of A that contains a pivot is a pivot column. A column of A with no pivot is a free
column. This split is the single most useful thing REF gives you, and Section 7 explains why.

      ☞ The intuition
   REF is a triangle of zeros in the bottom-left corner. Once you have it, the last nonzero
   equation involves the fewest unknowns, so you can solve it first and climb upward. That
   climb is called back substitution.


      ✗ Watch out
   REF is not unique. Different people doing different legal moves land on different REF
   matrices from the same start. That is fine. What is the same for everyone is which columns
   hold the pivots, and so how many pivots there are.

5 RREF: clean above the pivots too
Make every pivot equal to 1, then clear its column above and below. Now the answer
can be read straight off the page.

A matrix is in reduced row echelon form, or RREF, when it is in REF and also:

E4. Every pivot equals 1.

E5. In a pivot’s column, every other entry is 0 — above it as well as below it.

Reducing the REF matrix above to RREF gives:

                                    1 12 0 0 2
                                                
                                             5
                                   0 0 1 0 − 11 
                                              5 
                                  
                                   0 0 0 1  3   
                                             5
                                                 
                                    0 0 0 0  0

The extra work buys you something real. In RREF each pivot variable appears in exactly one
equation, with coefficient 1. So there is no back substitution left to do. You just read the answer.
Going all the way to RREF is called Gauss–Jordan elimination. Stopping at REF and climbing
back up is called Gaussian elimination.

      ✽ Wait — really?
   REF is not unique, but RREF is. Every matrix has exactly one RREF, no matter which legal
   moves you use or in which order. So two people who both reduce fully must end up with
   identical matrices. If your RREF differs from a friend’s, one of you made an arithmetic
   slip.

6 Rank: just count the pivots
The rank of a matrix is the number of pivots in its echelon form. Nothing more.

The rank of a matrix A, written rank( A), is the number of pivots in any REF of A. Equivalently,
it is the number of nonzero rows once you finish eliminating.
Three facts you will use constantly:

 • rank( A) counts the genuinely independent equations. Rows that are combinations of other
   rows collapse to zero and contribute nothing.

 • For an m × n matrix, rank( A) ≤ min(m, n). You cannot have more pivots than rows, and
   you cannot have more than one pivot per column.

 • rank([ A | b]) ≥ rank( A), always. Adding a column can only keep the pivot count the same
   or push it up by one.

That last point matters more than it looks. The extra column b can supply at most one new pivot.
So there are only two possibilities: rank([ A | b]) = rank( A), or rank([ A | b]) = rank( A) + 1.
The whole theory of Section 7 hangs on which of these two happens.

      ☞ The intuition
   Rank is the amount of real information in the system. Five equations of rank 3 means two
   of them were repeats in disguise, and you truly have only three constraints.


      ✗ Watch out
                                                                                       1 2
   Count pivots, not nonzero entries, and count them in echelon form. The matrix         24    has
   four nonzero entries but rank 1, because R2 − 2R1 wipes the second row out.

7 The two-switch test: 0, 1, or infinitely many
Compare rank( A) with rank([ A | b]), then compare it with n. Those two comparisons
decide everything.

A system is consistent if it has at least one solution, and inconsistent if it has none. Let A be
m × n, so n is the number of unknowns, and write r = rank( A).

   The rank criterion (Rouché–Capelli theorem)
    • If rank( A) < rank([ A | b]), the system has no solution.
    • If rank( A) = rank([ A | b]) = n, the system has exactly one solution.
    • If rank( A) = rank([ A | b]) = r < n, the system has infinitely many solutions,
      described by n − r free parameters.

Read it as two switches, checked in order.
Switch 1: is it consistent? During elimination, watch for a row that reads [ 0 0 · · · 0 | c ] with
c ̸= 0. As an equation that says 0 = c, which is false. One such row and the system is dead. In
rank language, that row is a pivot in the b column, so rank([ A | b]) exceeds rank( A).
Switch 2: how many answers? Given consistency, compare r with n. If every unknown owns a
pivot, each one is pinned down and the answer is unique. If some unknown has no pivot, it is
free to be anything, and each choice gives a different solution. So the count of free unknowns is
n − r, and any n − r > 0 means infinitely many solutions.




Figure 2: Two unknowns, so each equation is a line. The three cases of the rank criterion are the
only three ways two lines can sit. Notice there is no picture for “exactly two solutions” — that
case cannot exist.

      ✽ Wait — really?
   A linear system can never have exactly 2, or 7, or 100 solutions. It has 0, or 1, or infinitely
   many. The reason is short: if u andv both solve Ax = b, then so does u + t(v − u) for
   every real t, because A u + t(v − u) = b + t(b − b) = b. Two answers force a whole line
   of them.

8 Free variables and the shape of the answer
Every solution is one fixed answer plus anything the free variables are allowed to add.

Suppose the system is consistent with r pivots and n unknowns, and r < n. Here is the
procedure that turns RREF into a written answer.

1. Mark the pivot columns. Their variables are basic variables.

2. Every remaining variable is a free variable. There are n − r of them.

3. Give each free variable its own parameter: xfree = s, t, and so on.

4. Each row of the RREF now reads “one basic variable = number − (stuff involving the free
   variables)”. Write it out.

5. Collect the whole thing into vector form.

The vector form always looks like this:
                              x =          xp             + s v1 + t v2 + · · ·
                                          |{z}              |      {z        }
                                    particular solution        null space part

where x p is what you get by setting every free variable to zero, and the vectors v1 , v2 , . . . solve
the matching homogeneous system Ax = 0. The set of all solutions of Ax = 0 is called the
null space of A, and its dimension is n − r. That statement, rank( A) + nullity( A) = n, is the
rank–nullity theorem.




Figure 3: Left: the solutions of Ax = b from Problem 4 form a line that does not pass through
the origin. Right: the solutions of Ax = 0 form the parallel line through the origin. The two are
the same direction; x p just shifts one onto the other.

      ⋆ Everyday picture
   A bus route and a bus timetable. The null space is the route: the set of directions you are
   allowed to move. The particular solution is where the bus starts. Every valid position is
   start point plus some distance along the route.

   Number of free variables = n − r. That single number tells you whether the answer is a
   point (0 free), a line (1 free), a plane (2 free), and so on.

9 Homogeneous systems get a free pass
When b = 0, the system always has an answer. The only question is whether it has more
than the boring one.

A system is homogeneous when b = 0, that is Ax = 0. Setting every unknown to zero always
works, so x = 0 is always a solution. It is called the trivial solution.
This means Switch 1 can never fail. The last column of [ A | 0] is all zeros, and row operations
keep it all zeros, so rank([ A | 0]) = rank( A) automatically. A homogeneous system is never
inconsistent.
So only Switch 2 is live:

        r = n =⇒ only x = 0;       r < n =⇒ infinitely many, with n − r free variables.

One consequence is worth memorising. If a homogeneous system has more unknowns than
equations, then r ≤ m < n, so r < n is forced. A homogeneous system with more unknowns
than equations always has a nonzero solution.

      ✓ Key takeaway
   Homogeneous: never inconsistent. Either the trivial solution alone, or a whole subspace
   of solutions of dimension n − r.

10 The recipe, and the four mistakes
One checklist covers every problem in this set.


   Standard attack
    1. Write [ A | b], columns lined up, missing terms as 0.
    2. Row-reduce to REF. Work left to right, one pivot column at a time, clearing everything
       below each pivot before moving on.
    3. Read rank( A) (pivots in the first n columns) and rank([ A | b]) (pivots overall).
    4. Switch 1: if rank( A) < rank([ A | b]), stop and write “no solution”.
    5. Switch 2: if rank = n, unique. If rank = r < n, infinitely many with n − r parameters.
    6. If a solution is wanted, continue to RREF, name the free variables, and write the vector
       form.
    7. Substitute your answer back into the original equations.


      ✗ Watch out
   The four mistakes that cost the most marks:
 M1. Dividing by a parameter. If a pivot is k − 3, you may not divide by it until you have
     said k ̸= 3, and you must handle k = 3 as its own case.
 M2. Two operations that share a source row in one step. Doing R2 → R2 − 2R1 and
     R1 → R1 + R2 “simultaneously” is ambiguous. One at a time, and write down what
     you did.
 M3. Calling [ 0 0 0 | 0 ] inconsistent. That row is harmless. Only [ 0 0 0 | c ] with c ̸= 0 kills
     the system.
 M4. Counting free variables as n − m. It is n − r. Equations that collapse to zero rows do
     not count.

11 Problem 1 — A 2 × 2 system, done twice

      ✍ Problem 1 · Easy
   Solve the system below. Do it first by reducing to REF and back substituting, then again
   by going all the way to RREF. State rank( A), rank([ A | b]) and the number of unknowns,
   and use them to justify the number of solutions.

                                             x + 2y = 8
                                             3x − y = 3


What this tests. The mechanics of one elimination step, and the difference between stopping at
REF and pushing on to RREF.

      ✎ Worked example: Problem 1, method 1 — REF and back substitution
   Step 1.      Write the augmented matrix. Two unknowns, so n = 2.
                                                            
                                                      1 2 8
                                         [ A | b] =
                                                      3 −1 3

   Step 2.      Clear below the first pivot. The pivot is the 1 in position (1, 1). To kill the 3
                under it, use R2 → R2 − 3R1 . Compute the new row entry by entry:

                           3 − 3(1) = 0,  −1 − 3(2) = −7,      3 − 3(8) = −21.
                                                                     
                                   1 2 8     R2 → R2 −3R1   1 2     8
                                            −−−−−−−→
                                   3 −1 3                   0 −7 −21
                This is REF. Pivots are 1 (column 1) and −7 (column 2).
   Step 3.      Read the ranks. Two pivots inside the first two columns, so rank( A) = 2. No
                pivot appears in the b column, so rank([ A | b]) = 2 as well. And n = 2.
   Step 4.      Classify. Since rank( A) = rank([ A | b]) = 2 = n, the system has exactly one
                solution.
   Step 5.      Back substitute. The last row says −7y = −21, so y = 3. The first row says
                x + 2y = 8, so x = 8 − 2(3) = 2.
   Step 6.      Check in the originals. 2 + 2(3) = 8 ✓ and 3(2) − 3 = 3 ✓.

    Answer. x = 2, y = 3. Unique, because rank( A) = rank([ A | b]) = 2 = n.


      ✎ Worked example: Problem 1, method 2 — all the way to RREF
   Step 1.      Start from the REF above.
                                                                   
                                                   1 2   8
                                                   0 −7 −21

   Step 2.      Make the second pivot equal to 1. Scale with R2 → − 17 R2 :
                                                               
                                                        1 2 8
                                                        0 1 3

                                         x+y+z = 3

14 Problem 4 — A whole line of answers

      ✍ Problem 4 · Medium
   Solve
                                              x+y+z = 3
                                            2x + 3y + z = 5
                                           3x + 4y + 2z = 8

    The facts
    • Pivot = first nonzero entry in a row. Rank = number of pivots.
    • REF: staircase, zeros below each pivot, zero rows last. Not unique.
    • RREF: also pivots = 1 with zeros above them. Unique.
    • Free variables = n − r. Pivot columns give basic variables.
    • General solution = particular solution + null space.
    • Rank–nullity: rank( A) + nullity( A) = n.
    • Homogeneous Ax = 0 is never inconsistent. Only x = 0 if r = n, otherwise a subspace
      of dimension n − r.
    • More unknowns than equations, and homogeneous: non-trivial solutions guaranteed.
    • rank( A) ≤ min(m, n), and rank([ A | b]) is either rank( A) or rank( A) + 1.
    • Square A: rank( A) = n is the same as det( A) ̸= 0, the same as A invertible.

    The order of work
    Augment → REF → read both ranks → switch 1 (consistent?) → switch 2 (unique or
    many?) → RREF if a solution is wanted → substitute back into the originals.



      ✓ Key takeaway
   Two comparisons settle every linear system you will ever meet. Compare rank( A) with
   rank([ A | b]) to learn whether an answer exists. Compare rank( A) with n to learn how
   many.
