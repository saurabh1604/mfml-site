  Concept 1  Algebraic vs. geometric multiplicity

  Let λ be an eigenvalue of an n × n matrix A.
  Algebraic multiplicity am(λ) — how many times λ occurs as a root of the characteristic
  polynomial det(A − λI). (E.g. a factor (λ − 3)2 means am(3) = 2.)
  Geometric multiplicity gm(λ) — the number of independent eigenvectors for λ, i.e. the
  dimension of the eigenspace:

                          gm(λ) = dim ker(A − λI) = n − rank(A − λI).

 The key facts. (i) 1 ≤ gm(λ) ≤ am(λ) for every eigenvalue. (ii) A is diagonalizable
 ⇐⇒ gm(λ) = am(λ) for every eigenvalue (enough eigenvectors to fill a basis). (iii) If an
 eigenvalue has gm < am, the matrix is defective and cannot be diagonalized.

  Concept 2  The eigenvalue toolkit (used in several problems)

  If Av = λv (with v ̸= 0), then the eigenvalues transform predictably — the eigenvector stays
  the same:

              Powers:          Ak v = λ k v         ⇒       λk is an eigenvalue of Ak .
              Polynomials: if p(t) = c0 + c1 t + · · · + cm tm , then p(A)v = p(λ)v.
              Inverse:         if A is invertible (λ ̸= 0), A−1 v = λ1 v.
              Transpose:       AT has the same eigenvalues as A.

  Two consequences let you avoid brute-force matrix multiplication. Writing the eigenvalues as
  λ1 , . . . , λn :
                                      X                    Y
                             tr(A) =      λi ,   det(A) =      λi
                                            i                           i
                                        X                                      k       Y
                   =⇒       tr(Ak ) =       λik ,           det(Ak ) = det A        =       λik .
                                        i                                               i
  So to handle a high power, first find the eigenvalues, then work entirely with the scalars λi .

   Problem 7  Eigenvalues of a matrix polynomial p(A) [4 marks]

   Let A be a 3 × 3 matrix whose eigenvalues are 1, 2, 4, and define

                                        B = A2 − 5A + 6I.

  (a) Show that if λ is an eigenvalue of A (with eigenvector v), then λ2 − 5λ + 6 is an eigenvalue
  of B (with the same eigenvector). (b) Hence find the eigenvalues of B, then det(B) and tr(B),
  and state whether B is invertible. (c) For which eigenvalues of A would B fail to be invertible?


    Solution

(a) Spectral mapping.       Suppose Av = λv. Then A2 v = A(λv) = λ2 v, and so

                   Bv = (A2 − 5A + 6I)v = λ2 v − 5λv + 6v = (λ2 − 5λ + 6)v.

Thus v is still an eigenvector, now with eigenvalue p(λ) = λ2 − 5λ + 6.

(b) Eigenvalues of B and consequences.             Apply p(λ) = λ2 − 5λ + 6 to each eigenvalue of A:

           p(1) = 1 − 5 + 6 = 2,      p(2) = 4 − 10 + 6 = 0,       p(4) = 16 − 20 + 6 = 2.

So B has eigenvalues {2, 0, 2}. Therefore

                         det(B) = 2 · 0 · 2 = 0,       tr(B) = 2 + 0 + 2 = 4.

Because 0 is an eigenvalue (equivalently det B = 0), B is not invertible — even though A itself is
(none of its eigenvalues is 0).

(c) When is B singular? B is singular exactly when p(λ) = 0 for some eigenvalue λ of A. Since
p(λ) = (λ − 2)(λ − 3), this happens iff A has 2 or 3 as an eigenvalue. Here λ = 2 occurs, which is
why B is singular.

Remark (Cayley–Hamilton).  If A’s characteristic polynomial were equal to p(λ) = λ2 − 5λ + 6 — e.g.
for A = −4 5 with eigenvalues 1, 4 and char. poly λ2 − 5λ + 4 — then p(A) collapses to a multiple
           0 1
               

of I: indeed A2 − 5A + 4I = 0 gives A2 − 5A + 6I = 2I.

  Answer. p(λ) = λ2 − 5λ + 6 maps each λ; eigenvalues of B are 2, 0, 2. det(B) = 0, tr(B) = 4,
  so B is not invertible. B is singular iff A has eigenvalue 2 or 3 (the roots of p).
