   Problem 1 (4 marks) EASY COMPUTATION

 Let f (x) = 2x3 − 9x2 + 12x + 5.
  (a) Find all stationary points of f .                                                             [2]
  (b) Classify each using the second-derivative test and evaluate f there.                          [1]
  (c) Does f possess a global minimum over R? Justify.                                              [1]


 Step-by-step solution


 Step 1 (set the gradient to zero). Differentiate and factor:
                               f ′ (x) = 6x2 − 18x + 12 = 6(x − 1)(x − 2).
 So f ′ (x) = 0 at x = 1 and x = 2.

 Step 2 (second-derivative test). Here f ′′ (x) = 12x − 18.
 f ′′ (1) = −6 < 0 ⇒ local maximum at x = 1,              f ′′ (2) = +6 > 0 ⇒ local minimum at x = 2.

 Step 3 (values).
                     f (1) = 2 − 9 + 12 + 5 = 10,       f (2) = 16 − 36 + 24 + 5 = 9.

 Step 4 (global check). As x → −∞, f (x) → −∞ (odd degree). The function is unbounded
 below, so x = 2 is only a local minimum.

  Answer. x = 1: local max, f = 10.            x = 2: local min, f = 9.        No global minimum – a
  cubic is unbounded.

 The standard 4-marker: factor the derivative (try integer roots first), test curvature, then – the
 step students skip – check the behaviour at ±∞ before saying “global”. A cubic never has a
 global minimum or maximum.

 work in a table – point, gradient, new point, f – so no bookkeeping marks are lost. Each

   Problem 4 (4 marks) EASY COMPUTATION

 Let f (x, y) = x2 + y 2 − 2x − 4y + 5.
  (a) Find the exact minimizer (x∗ , y ∗ ) and the minimum value.                                     [1]
  (b) Run two GD iterations from (0, 0) with γ = 0.25, reporting f each time.                         [3]

 So f : 5 → 1.25 → 0.3125, closing in on (1, 2).

 The safe routine for any f = ax2 + by 2 : (1) write the trial point with factors (1 − ci γ), where

 The complete exam story in one question: normal equations give the destination, GD gives the
 journey, the Hessian explains the driving style. The reusable diagnostic is the number 1 − γλ:

 Intuition & exam tips

 Fix the decision rule before starting – slope negative ⇒ discard the left half, slope positive ⇒
 discard the right half – and the trace is free marks. The width formula (b − a)/2k plus one log2
 finishes part (b) in two lines. If the paper swaps in golden-section search, the interval shrinks
 by factor 0.618 per evaluation instead; if h is not unimodal, the exact bracketing methods fail
 and the (inexact) Armijo rule is the fallback.
